=== Pentarch Live Edit ===
Stable tag: 2.7.3

Live Edit 1.x (inline editing, Live Blocks, site-wide zones) plus:
* PLE Builder: "Edit with PLE" on any page or post. Sections, rows, columns and widgets, a Layers panel, desktop/tablet/phone styles, a code view, the Media Library, blank-canvas layout.
* PLE Studio at /studio/: a mobile-first web design course (19 lessons with automatic checks), visual builder and code projects, publishing, classes, assignments, teacher review and certificates. Installable as an app (PWA) and usable offline.
Settings: Live Edit > PLE Studio.
* Design Lab in Studio (/studio/#/lab): a 10-step Get started tour, a template makeover (watch it, then do it yourself), 54 section designs in 14 topics (hero banners, menus, about, team, services, journeys, testimonials, stats, pricing, calls to action, galleries, FAQs, contact, footers) with Watch (a cursor clicks through the real editor), Build with guide (each step ticks as you do it) and Practice (rebuild a live target, check your score, ask for hints), four client briefs, and My parts (save any finished design or section and add it to any website).
* Teachers can attach Lab tasks to class assignments and see how many designs each student has built.
* The WordPress builder includes all 54 designs as ready-made "Designer sections" with hover previews.
