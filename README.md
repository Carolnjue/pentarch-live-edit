# Pentarch Live Edit (PLE)

WordPress plugin by Pentarch Systems Solutions.

- **Live Edit**: edit hand-built pages on screen, Live Blocks and site-wide zones.
- **PLE Builder**: "Edit with PLE" on any page or post. Sections, rows, columns, widgets, a Layers panel, desktop/tablet/phone styles, a code view and the Media Library. Works on phones.
- **PLE Studio** (`/studio/`): a mobile-first platform for teaching web design. It has 19 practical lessons with automatic checks, builder and code projects, publishing, classes, assignments, teacher review and certificates. It installs like an app and works offline.

## Updates
Sites check this repository and update themselves when the `Version:` in `pentarch-live-edit.php` goes up. Use **Live Edit > PLE Studio > Check for updates now** to update straight away.

Each site keeps its own Live Edit 1.x core files (`includes/class-ple-legacy.php`, `assets/editor.css`, `assets/editor.js`) through every update.
